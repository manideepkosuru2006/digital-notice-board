# 🌟 Campus Pulse – Interactive Digital Notice Board

**Campus Pulse** is a modern digital notice board designed to make campus communication faster, organized, and accessible. It provides separate experiences for **students** and **authorized staff**, with interactive notice management and discovery features.

## ✨ Interactive Highlights

### 1. 🎓 Student Notice Board Feed

* **Header & Navigation:** Brand title, role toggle (`Student Board` / `Authorized Staff Portal`), user avatar, and light/dark theme switcher.
* **Search & Discovery:** Real-time search across notice titles, departments, and reference codes.
* **Smart Filters:** Filter notices by:

  * Department – Computer Science, ECE, Mech, Civil, Biotech
  * Target Year – 1st, 2nd, 3rd, 4th Year
  * Priority
  * Category – Academic, Exams, Placements, Events, Sports
* **Interactive Notice Cards:**

  * 📌 Pinned notices
  * 🚨 Urgent alerts with red pulse animation
  * 🔊 **Listen** – Text-to-speech notice reader
  * 🖨️ **Print** – Generate an official letterhead PDF
  * 📖 **Read Full** – Open the complete notice in a modal

---

### 2. 🔐 Authorized Staff Portal

The staff dashboard provides tools to create, monitor, and manage campus announcements.

#### 📊 Dashboard Metrics

Quick overview of:

* Published Notices
* Total Views
* Urgent Alerts
* Pending Drafts

#### 📝 Notice Creator

Staff can create announcements using an interactive modal form with:

* Notice title and content
* Department and target audience
* Target year
* Priority level
* Venue/location
* Attachment simulation
* Pinning controls
* Publish or save as draft options

#### 📋 Notice Management

A management table provides complete control over announcements:

* Published / Draft / Archived status
* Pin/unpin notices
* Edit notices
* Print notices
* Delete notices
* Manage existing announcements

## 🎯 Project Goal

Campus Pulse aims to replace traditional physical notice boards with a **centralized, interactive, and accessible digital platform** that improves communication between college administration, staff, and students.
